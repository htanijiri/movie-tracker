# movie-tracker

見たいと思った映画を忘れず、見るまで・見た後まで管理する、自分のための映画リスト。
映画館の予告で「面白そう」と思ったのに、本編を見終わる頃には作品名を忘れてしまう、という問題が出発点。
スマホと PC のブラウザで使う Web アプリで、現在の利用者は作者1人（Google ログインで制限）。

## 設計の前提（なぜこの作りか）
- **映画館の中では端末を操作しない。** 上映中や予告の間にメモを取ることを前提にしない。見終わってから、または帰宅してから登録する。
- **「どこまでなら見たいか」を区別する。** 同じ「見たい」でも、「劇場で見たい」「サブスクで配信されたら見たい」「今回は見送る」は意味が違うので、分けて残す。
- **「どう知ったか」を残す。** 一般的な映画サービスが「見る → 評価する」を中心にしているのに対し、このアプリは「知る → 気になる → どこで見るか決める → 忘れない → 見る → 記録する」までを扱う。
- **入力を少なくする。** 登録はワンタップ。きっかけや感想は任意で、あとから書ける。
- **スクレイピングをしない。** 映画の情報は、API を正式に公開している TMDb だけから取得する。
- **まず自分が日常的に使えるものを作る。** 配信開始の通知、予告の特定、他の利用者との共有などは、あとの段階に回している。

詳しい経緯は [docs/HISTORY.md](docs/HISTORY.md)、進捗は [TASKS.md](TASKS.md)、仕様は [docs/specs/](docs/specs/README.md) を参照。

## 主な機能
- 映画を探す：タイトル検索、公開中・近日公開の一覧
- 映画詳細：ポスター、あらすじ、ジャンル、予告動画、日本での配信状況
- 見たい映画の登録：劇場で見たい／サブスクで見たい／見送る（ワンタップ）
- 知ったきっかけの記録：映画館の予告、CM、SNS など
- 視聴済みの記録：見た日、視聴方法、場所・サービス名、評価（★5段階）、感想
- トップページ：「劇場で見たい」「サブスク待ち」「最近見た」を分けて表示
- Google ログイン（許可したアカウントだけが使える）
