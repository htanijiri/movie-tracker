# 010 公開終了・見逃しの管理

- 状態：完了
- 依存：007

## 👤 ユーザーが確認するところ

### 何のための機能か
「劇場で見たい」にした映画を、上映が終わる前に見に行けるようにする。いまは公開日しか出ないので、公開からどのくらい経ったのかが分かりにくい。

### できるようになること
- 「劇場で見たい」の映画のうち、公開済みのものに **「公開◯週目」** を出す（公開日から6日目までが1週目）。
- **公開から4週間（28日）を過ぎたら、「公開◯週目・そろそろ上映終了かも」と目立つ色で出す。**
- 表示する場所：トップページとリストの「劇場で見たい」のカード、その映画の詳細画面。
- 上映の終了日のデータはどこにもないので、あくまで公開日からの目安。実際の上映状況は映画館のサイトで確かめる。
- 見逃したあとに配信が始まれば、仕様書 009 の配信開始チェックで分かる（「劇場で見たい」のままでも対象になる）。

表示の例（今日が 2026/11/10 の場合）：
```
[🎬 劇場で見たい] 公開2週目               ← 11/1 公開
[🎬 劇場で見たい] 公開6週目・そろそろ上映終了かも  ← 10/1 公開
```

### やらないこと
- 映画館ごとの上映スケジュールや、実際の上映終了日の表示（データの取得元がない）。
- 「劇場で見たい」以外の映画への表示。
- 通知（アプリの表示だけ）。

### チャットで決めたこと
| 決めたこと | 理由 |
|---|---|
| 「そろそろ上映終了かも」は、公開から4週間を過ぎたら出す | 多くの映画は、公開から3〜6週間で上映回数が減ったり終わったりする。早めに気づける |

## 🤖 実装メモ（Claude 用。ユーザーは読まなくてよい）

### 受け入れ条件
- [x] AC1：公開日からの経過日数 `d`（日本時間の今日 − 公開日）に対して、`d` が 0〜6 なら「公開1週目」、7〜13 なら「公開2週目」…（`floor(d / 7) + 1`）を返す（自動テスト）
- [x] AC2：`d >= 28` のとき「公開◯週目・そろそろ上映終了かも」になり、注意の表示（`data-release-warning`）が付く。27 日では付かない（自動テスト）
- [x] AC3：公開前・公開日未定の映画には、この表示を出さない（仕様書 011 の表示になる）（自動テスト）
- [x] AC4：トップページとリストの「劇場で見たい」のカードに出る。「サブスク待ち」「視聴済み」「見送り」のカードには出ない（自動テスト）
- [x] AC5：詳細画面で、記録が「劇場で見たい」の映画にだけ、公開日の横に同じ表示が出る（自動テスト）
- [x] AC6：幅 375px で、カードの表示が崩れず横スクロールが出ない（手動：Claude）

### 設計方針
- `app/lib/release.ts`（画面とサーバーの両方で使う）に `releaseStatus(releaseDate, today)` を置き、`{ kind: "upcoming" | "showing" | "unknown", label, warning }` を返す。011 の近日公開の表示も同じ関数にまとめる。`MovieCard` の `releaseLabel` はこれに置き換える。
- 詳細画面は、`record.status === "WANT_TO_WATCH" && record.preferredMedium === "THEATER"` のときだけ表示する（2016年公開の映画に「公開500週目」と出さないため）。

### 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| 公開日からの週数で判断する | ○ | 取得できるデータはこれだけ |
| TMDb の「公開中」の一覧に入っているかで判断する | × | TMDb の「公開中」も公開日から機械的に決まっているだけで、実際の上映とは関係しない |

### 検証方法
- 自動テスト：日付を固定して `releaseStatus` を確かめ、カードと詳細画面の描画を確かめる。
- 手動確認（Claude）：AC6。
