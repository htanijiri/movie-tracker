# 006 視聴済みの記録（日付・視聴方法・場所・評価・感想）

- 状態：合意済み
- 依存：004

## 👤 ユーザーが確認するところ

### 何のための機能か
見た映画について、いつ・どこで・どうやって見たかと、感想を残す。

### できるようになること
- 映画詳細の画面の「見た」ボタンから、見た記録を付けられる。見たいリストに入れていなかった映画にも、直接付けられる。
- 記録する内容：
  - 見た日（最初から今日の日付が入っている）
  - 視聴方法：劇場／サブスク配信／レンタル・購入／その他（「劇場で見たい」にしていた映画は劇場、「サブスクで見たい」にしていた映画はサブスク配信が、最初から選ばれている）
  - 場所・サービス名（例：映画館の名前、配信サービスの名前。以前に入力したものが候補に出る。任意）
  - 評価：★1〜5（任意）
  - 感想（任意）
- 日付と視聴方法は最初から入っているので、「見た」→「保存」の2回押すだけで記録できる。評価や感想は、あとから書き足せる。
- 見た記録は、あとから直せる。「見た記録を取り消す」で、見る前の状態（劇場で見たい／サブスクで見たい／見送り）に戻せる。

### 使い方の流れ
1. 映画の詳細を開き、「見た」を押す。
2. 日付と視聴方法を確かめ、必要なら場所・評価・感想を入れて「保存」を押す。
3. トップページの「最近見た」に表示される（仕様書 007）。

### やらないこと
- 同じ映画を2回以上見た記録を別々に残すこと（1本につき記録は1つ。見直したときは上書きする）。
- ★0.5 刻みの評価。
- 感想の公開・共有、ネタバレの伏せ字。

### チャットで決めたこと
| 決めたこと | 理由 |
|---|---|
| 評価は★5段階（付けなくてもよい） | ワンタップで選べ、入力が最も少ない |

- 完成後に手で確認するもの：なし（使い心地は、仕様書 007 の「初期データの登録」で合わせて確かめる）

## 🤖 実装メモ（Claude 用。ユーザーは読まなくてよい）

### 受け入れ条件
- [ ] AC1：`intent=save-watched` で日付と視聴方法を POST すると、`status=WATCHED`、`watched_at`、`watched_medium` が保存される。`preferred_medium` と `discovery_*` は変わらない（自動テスト）
- [ ] AC2：未登録の映画に `save-watched` を POST すると、`status=WATCHED`、`preferred_medium=NULL` の行が新しくでき、`movies` のスナップショットも作られる（自動テスト）
- [ ] AC3：`watched_at` は `YYYY-MM-DD` の実在する日付で必須。今日（`Asia/Tokyo`）より後の日付は 400。`watched_medium` は `THEATER`／`STREAMING`／`RENTAL`／`OTHER` だけを受け付ける（自動テスト）
- [ ] AC4：`rating` は空または 1〜5 の整数だけを受け付ける。`watched_place` は100文字、`review` は5000文字まで。違反は 400 で、入力内容を保ったままエラーを表示する（自動テスト）
- [ ] AC5：すでに `WATCHED` の映画に `save-watched` を POST すると、同じ行が上書きされる（行は増えない）（自動テスト）
- [ ] AC6：`intent=unwatch` で `watched_*`・`rating`・`review` が NULL になり、`preferred_medium` が `THEATER`／`STREAMING` なら `WANT_TO_WATCH`、`NONE` なら `SKIPPED` に戻る。`preferred_medium` が NULL（直接「見た」を付けた映画）の場合は行を削除する（自動テスト）
- [ ] AC7：フォームの初期値は、見た日＝今日（`Asia/Tokyo`）、視聴方法＝`preferred_medium` が `THEATER` なら `THEATER`、`STREAMING` なら `STREAMING`、それ以外は未選択（自動テスト：loader の戻り値）
- [ ] AC8：場所・サービス名の候補は、選択中の視聴方法と同じ `watched_medium` で過去に入力した `watched_place`（劇場のときは `discovery_place` も含む）を、重複なしで新しい順に最大10件。他の利用者の入力は出ない（自動テスト）
- [ ] AC9：感想の改行は表示でも改行され、HTML タグはエスケープされる（自動テスト）
- [ ] AC10：`status=WATCHED` の詳細画面では、3つのボタン（004）の代わりに、見た日・視聴方法・場所・★・感想と「編集」「見た記録を取り消す」が表示される（自動テスト）
- [ ] AC11：ブラウザで、見た記録の入力・保存・編集・取り消しができ、★をタップで選べる（手動：Claude）

### 設計方針
- **action**：`/movies/:tmdbId` の action に `intent=save-watched` と `intent=unwatch` を足す。
- **視聴方法の値**：`watched_medium` は `THEATER`／`STREAMING`／`RENTAL`／`OTHER`（`preferred_medium` とは別の値の集合。`RENTAL` はレンタルと購入をまとめる）。
- **日付**：Workers は UTC で動くので、「今日」は `Asia/Tokyo` で計算する共通関数（`todayInTokyo()`）を使う。005 と共有する。
- **画面**：「見た」を押すとフォームが開く（`<details>` またはページ内の展開）。★はラジオボタン5つを星の見た目にする（キーボードとスクリーンリーダーで操作できる）。取り消しは `<dialog>` で確認する（感想が消えるため）。
- **AC6 の行削除**：直接「見た」を付けた映画は、戻す先の状態がないため行ごと消す。確認ダイアログの文言で「リストから消えます」と伝える。

### 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| 映画の記録の中に見た記録を1つ持つ | ○ | BRIEF のデータ設計どおり。Phase 1 では足りる |
| 視聴の記録を別テーブルにして複数回に対応 | × | 再鑑賞の記録は BRIEF の要件にない。必要になったら移行する |
| 「見た」を押した瞬間に今日の日付で保存 | × | 後日まとめて記録することが多く、日付の誤りに気づきにくい。確認して保存する2回押しにする |

### 検証方法
- 自動テスト：action と loader、候補のクエリを D1 に対してテストする。
- 手動確認（Claude）：AC11。星の選択やダイアログの動きはブラウザで確かめる。
